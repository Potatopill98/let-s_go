# 合作逃生3D Demo（Godot 4.7）

## 游戏概述
3D第一人称多人合作逃生Demo，玩家从实验室被释放，需要修理大门、分配武器、修理升降平台，最终到达安全区逃生。所有美术资源均使用占位几何体。

## 操作说明
- **WASD**：移动
- **Shift**：奔跑
- **空格**：跳跃
- **Q**：闪避（位移）
- **左键**：攻击（挥拳/武器攻击）
- **E**：交互（修理/拾取，按住持续修理）
- **1/2**：切换武器
- **R**：手枪换弹
- **ESC**：释放/锁定鼠标

## 关卡流程
### 第一层（出生区域）
- 从实验室门口出生，身后刷怪
- 核心任务：修理大门（绿色区域按住E）
- 无武器，只能挥拳击退怪物
- 修理进度越高，刷怪越快
- 修完门进入下一层

### 第二层（武器分配区）
- 入口处有武器台：木棒（近战）、手枪（远程），按E拾取自行分配
- 核心任务：修理升降平台
- 怪物持续从入口门涌入
- 修理完成后触发15秒撤离倒计时
- 必须站在上升平台上才能到达第三层，没站上去的留在第二层

### 第三层（安全区）
- 平台上升到顶到达第三层
- 有复活点，倒地队友可在此复活
- 走到绿色通关区域即胜利

## 已完成模块
1. 玩家控制器：移动、奔跑、跳跃、闪避、挥拳、受击硬直、武器系统
2. 怪物AI：追击、攻击、受击击退、死亡，稳定不卡
3. 武器系统：木棒近战、手枪远程、地面拾取、切换、换弹
4. 交互系统：按住E持续交互、多人同修速度叠加、大门自动打开
5. 刷怪系统：动态刷怪，速度随修理进度提升
6. 升降平台：修理完成倒计时、自动上升带动玩家
7. UI系统：操作提示、交互提示、进度条、消息通知、撤离倒计时
8. 通关流程：三层完整流程，到达第三层绿色区域通关

## 技术规范
- Godot 4.7
- GDScript所有变量显式类型，禁止:=类型推断
- 所有占位几何体均有自发光，场景明亮无黑屏
- 模块化开发，各功能独立可拆分
