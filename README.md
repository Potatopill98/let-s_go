# 合作逃生3D Demo（Godot 4.7）v0.8

## 游戏概述
3D第一人称多人合作逃生游戏，玩家从实验室被释放，需要拾取扳手修理大门、分配武器、修理升降平台，穿越黑暗走廊，最终到达安全区逃生。核心玩法是**单手持物+分工配合**：拿扳手的人负责修理，拿武器的人负责战斗，拿手电筒的人负责照明。所有美术资源均使用占位几何体。

## 操作说明
- **WASD**：移动
- **Shift**：奔跑
- **空格**：跳跃
- **Q**：闪避（位移）
- **左键**：攻击（空手挥拳/武器攻击，拿工具时不能攻击）
- **E**：交互（修理/拾取/搜索/刷卡，按住持续修理）
- **G**：丢弃当前手持物品
- **R**：手枪换弹
- **F**：投掷背包中的投掷物
- **V**：放置背包中的放置物
- **1-4**：使用背包消耗品
- **ESC**：释放/锁定鼠标

## 手持物品系统（核心玩法）
- 玩家一只手同时只能拿**一个**物品
- **空手**：可以挥拳（低伤害+击退）
- **工具**（扳手/手电筒）：可以交互修理，**不能攻击**
- **武器**（木棒/手枪）：可以攻击，**不能修东西**
- 拾取新物品时自动丢掉当前物品
- 天然产生分工：有人修门、有人打怪、有人照明

## 关卡流程
### 第一层（出生区域）
- 从实验室门口出生，身后刷怪
- 地上有**扳手**，必须拾取扳手才能修理
- 核心任务：修理大门（绿色区域按住E）
- 无武器，只能挥拳击退怪物
- 修理进度越高，刷怪越快
- 修完门进入下一层

### 第二层（武器分配区）
- 入口处有武器台：木棒（近战）、手枪（远程），按E拾取自行分配
- 拿了武器就不能修东西，需要有人继续拿扳手
- 核心任务：修理升降平台（也需要扳手）
- 怪物持续从入口门涌入
- 修理完成后触发15秒撤离倒计时
- 必须站在上升平台上才能到达第三层，没站上去的留在第二层

### 第三层（安全区）
- 平台上升到顶到达第三层
- 有复活点，倒地队友可在此复活
- 可以继续前进到黑暗走廊

### 第四层（黑暗走廊）
- 狭长黑暗走廊，环境光极低，只有微弱红色应急灯
- 入口处有**手电筒**，必须拾取才能看清前路
- 拿了手电筒就不能拿武器，需要队友保护
- 走廊内有障碍物（箱子/油桶）可以绕
- 怪物从走廊深处刷新
- 走廊尽头是最终通关区域

## 已完成模块
1. 玩家控制器：移动、奔跑、跳跃、闪避、挥拳、受击硬直、单手持物系统
2. 怪物AI：追击、攻击、受击击退、死亡，稳定不卡
3. 手持物品系统：单手持物、工具/武器分类、自动丢弃、G键手动丢弃
4. 武器系统：木棒近战、手枪远程（实体子弹）、地面拾取、换弹
5. 工具系统：扳手（修理）、手电筒（照明）
6. 交互系统：按住E持续交互、多人同修速度叠加、工具需求检查、大门自动打开
7. 刷怪系统：动态刷怪，速度随修理进度提升，多层独立刷怪
8. 升降平台：修理完成倒计时、自动上升带动玩家
9. UI系统：操作提示、交互提示、进度条、消息通知、撤离倒计时、十字准心、手持物品显示
10. 通关流程：四层完整流程，黑暗走廊尽头通关
11. 场景美化：程序化氛围灯、发光墙面装饰、地面标记、体积雾、辉光效果
12. 程序化场景生成器：可随机生成障碍物、道具、灯光的完整地图

## 武器与工具说明
- **木棒**：近战范围攻击，前方120度2.5米，挥砍动画
- **手枪**：12发弹匣，实体子弹从枪口发射，R换弹，子弹有连续碰撞检测
- **扳手**：修理工具，拿了才能修门/修升降平台，不能攻击
- **手电筒**：照明工具，黑暗走廊必备，拿了不能攻击
- 拾取新物品时旧物品自动掉地上，按G可丢弃当前物品

## 技术规范
- Godot 4.7
- GDScript所有变量显式类型，禁止:=类型推断
- 所有占位几何体均有自发光，场景明亮无黑屏
- 模块化开发，各功能独立可拆分
- 子弹实体从枪口发射，飞出后独立运行与枪无关
- 连续碰撞检测防止高速子弹穿透
- 跨模块引用避免使用全局class_name，防止加载顺序错误
