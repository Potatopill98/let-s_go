# 实验室逃生 3D多人合作Demo
## 项目基础信息
- 开发引擎：Godot 4.7
- 代码规范：所有变量/函数返回值显式声明类型，完全禁用:=类型推断
- Demo版本：v1.0 单机完整流程版
- 美术资源：全部使用基础几何体占位，无外部资源依赖

---

## 一、游戏核心玩法
你和队友从破损的实验室中逃出，需要逐层完成修理任务，躲避/击杀源源不断涌出的怪物，最终搭乘升降平台抵达顶层完成逃生。
完整流程：
1. 第一层：手无寸铁，靠走位拉扯怪物，修理尽头大门
2. 第二层：在入口工作台拾取木棒/手枪，修理升降平台，倒计时结束后登机撤离
3. 第三层：复活掉队的队友，启动最终逃生开关，完成通关

## 二、操作说明
| 按键 | 功能 |
|------|------|
| W/A/S/D | 前后左右移动 |
| 鼠标移动 | 控制视角转头 |
| Shift | 奔跑 / 方向闪避 |
| 空格 | 跳跃 |
| 鼠标左键 | 攻击（无武器时挥拳，持武器时使用武器） |
| E | 交互（拾取武器、救援队友、复活队友） |
| R | 手枪换弹 |
| Esc | 释放鼠标退出视角锁定 |

## 四、当前已实现完整功能
### 玩家系统
- 标准第一人称FPS视角，鼠标平滑转向
- 行走、奔跑、方向闪避、跳跃、重力碰撞
- 徒手挥拳：1秒CD，低伤害，微弱击退（对怪和队友均生效）
- 完整生命状态机：正常→倒地→死亡→复活
- 倒地机制：血量耗尽后进入倒地状态，只能缓慢爬行，每秒自动掉1血，理论存活100秒，怪物攻击会加快死亡
- 队友救援：倒地玩家可被队友长按E救起，恢复半血
- 武器挂载：支持拾取并切换近战/远程武器

### 怪物AI系统
- 完整状态机：空闲→巡逻→追击→攻击→死亡
- 动态仇恨机制：优先攻击最近目标，被攻击后立刻锁定反击目标
- 普通地面怪：红色方块，移速较慢，血量50，低伤害，仅地面移动
- 第三层快速怪：橙色方块，移速更快，血量更低，攻击更高
- 死亡逻辑：血量清空后压扁，2秒后自动移除实体

### 任务系统
- 多人协作修理：单人可完成，多人同区域修理速度线性提升
- 进度永久保存，离开修理区域不会清空进度
- 大门任务：修理完成后自动开门，2秒后进入第二层
- 升降平台任务：修理完成后触发15秒撤离倒计时，平台自动上升，站在平台上的玩家会被同步带上高层，未登机玩家留在下层
- 最终逃生任务：修理完成后触发全局胜利结算

### 刷怪系统
- 刷怪速度完全绑定当前任务进度，修理进度越高，刷怪间隔越短，怪物越多
- 第一层刷怪点固定在实验室深处，怪物会自动沿路径向任务点移动
- 第二层刷怪点固定在入口，模拟怪物从第一层持续涌入，本地不刷新原生怪物
- 自动限制同屏最大怪物数量，避免性能溢出

### 场景与碰撞
- 所有地面、墙体、平台均有匹配的视觉网格和物理碰撞，不会穿模掉图
- 不同物体使用不同颜色材质区分：深灰地面、浅灰围墙、蓝色大门、红色怪物、橙色快速怪、绿色复活点、黄色开关
- 全封闭场景边界，玩家不会走出地图

## 五、运行方式
1. 打开Godot 4.7
2. 点击「导入」，选择本项目文件夹内的project.godot
3. 等待项目导入完成，按F5即可开始游戏
4. 第一次运行选择level_1.tscn作为主场景即可
