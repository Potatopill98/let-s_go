# 游戏设计文档大纲

## 1. 游戏概述
- 游戏名称：Lab Escape 3D Co-op
- 类型：3D第一人称多人合作逃生游戏
- 引擎：Godot 4.7
- 核心体验：实验室逃出→逐层推进→合作逃生
- 参考作品：BIGWORK后室、逃生试炼、Lethal Company

## 2. 核心玩法循环
- 进入新区域 → 探索收集 → 完成任务开门 → 防守逃生 → 进入下一层
- 单手持物系统：一次只能拿一个物品
- 背包系统：6格（2任务格+4消耗品格）
- 职业分工：工程师/医生/侦察兵/突击手
